# 合成大绿猫

双击根目录的 index.html 开始游戏。保持“图”和“v1”文件夹的相对位置。
手机或电脑浏览器均可游玩，无需安装依赖。

- 鼠标：移动瞄准、点击投放。
- 触屏：拖动瞄准、松手投放。
- 键盘：左右键移动，空格投放，R 重新开始。
- 相同等级接触后合成为下一级；最高等级两只相撞清场并奖励分数与复活币。

## 已确认的碰撞参数

v1/assets/fruits/parts.js 使用用户通过可视化编辑后导出的 D:/Downloads/parts.js，逐字节复制。
11 级顺序对应 图/1.png 至 图/11.png。
各级碰撞圆数量：4、2、4、3、2、4、2、4、1、1、3。
游戏直接读取此文件，不再从浏览器存储读取或覆盖碰撞配置。
编辑器、编辑入口及编辑用的内嵌图片副本均已移除。

如以后需要调整参数，可替换 v1/assets/fruits/parts.js。
每个 parts 项为 [ox, oy, s]，单位为该等级基础半径 r；rb 为包住所有子圆的粗筛半径。
实际图片尺寸与缩放应保持一致，避免图片与碰撞范围错位。

## 本地预览

也可在此目录运行：

```
python -m http.server 8765 --bind 127.0.0.1
```

打开 http://127.0.0.1:8765/。
