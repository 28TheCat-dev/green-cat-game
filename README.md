# 合成大绿猫 · 碰撞编辑器

双击根目录的 index.html 打开编辑器。保持 `图` 和 `v1` 文件夹的相对位置。
图片为 `图/1.png` 到 `图/11.png`（当前均为 512×512）；顺序对应合成等级。

1. 选择图片，拖圆内移动，拖右侧白色圆点调整半径。数值输入也可以微调。
2. 必要时添加辅助圆，多个圆共同组成一只猫，作为一个整体移动和旋转。
3. 保存到浏览器，或点击“保存并试玩”。试玩使用原项目物理引擎，并可显示碰撞圆。
4. 下载 parts.js，手动替换 v1/assets/fruits/parts.js，使分享出去的游戏也使用修改后的参数。

浏览器保存不会改写磁盘文件。若已替换 parts.js 但本机仍使用旧设置，在编辑器中导入新的文件后保存即可。
file:// 模式下不同浏览器的本地存储行为可能不同；编辑器内的试玩通过消息直接传递参数，不依赖跨页面本地存储。
也可在此文件夹运行 `python -m http.server 8765 --bind 127.0.0.1`，打开 http://127.0.0.1:8765/。

## 从其他工具获取圆形碰撞参数

坐标基于**实际用于游戏的整张图片**，原点在左上，X 向右，Y 向下。
编辑器支持粘贴像素参数，例如 `[[256,320,150]]`，并自动换算。
多边形顶点不能直接作为圆形参数导入；用多个重叠圆近似。

parts.js 是 11 个对象构成的数组，每个对象包含：

```js
{ rb: 0.909, parts: [[0, 0.27174, 0.63689]] }
```

每个 parts 项为 `[ox, oy, s]`，单位为该等级基础半径 r。
原引擎 `ASSET_FILL=0.92`，整图绘制边长为 `2*r/0.92`。
对于 512×512 图，换算单位 U = 512×0.92/2 = 235.52：

```
ox = (圆心X - 256) / 235.52
oy = (圆心Y - 256) / 235.52
s  = 像素半径 / 235.52
rb = 所有圆的 max(sqrt(ox² + oy²) + s)
```

rb 是以图片中心为圆心、包住全部子圆的粗筛包围圆，不是合成等级半径。
本编辑器按每级基础半径限制 rb，避免碰撞范围比棋盘宽还大。
裁切透明边距、移动主体或改变图片缩放后，需重新计算参数。

## 按图片主体轮廓生成

编辑器中点击“按主体轮廓生成”，使用最多 9 个内接圆近似主体。
预先排除了第 3 张的音符、第 4 张的 !?、第 5 张左侧符号、第 6 张顶部文字。
红色区域不参与自动计算；勾选“擦除文字 / 符号”后可继续涂抹排除区域，再点击生成。
擦除只影响碰撞蒙版，不修改原图片；手动改圆时仍需自行观察是否越入文字区域。
衣服印字是身体内部的颜色，不改变身体外轮廓，不会生成独立碰撞圆。
可选批处理脚本 tools/build_parts.py 基于原项目同名脚本，输入路径改为 图/1.png～11.png。
运行后输出单独的 v1/assets/fruits/auto-parts.js，可在编辑器中导入，不覆盖单圆默认值。
编辑器的 v1/assets/image-data.js 是当前 11 张图片的内嵌副本，让离线打开也能读取透明度。
如果替换原图，需要同步更新内嵌副本，避免编辑器与游戏图片不一致。
